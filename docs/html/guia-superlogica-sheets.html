1. Objetivo

Trazer para o Sheets os dados financeiros da Superlógica para conferência e análise.

Script de produção integrations/superlogica/src/superlogica-cobrancas-analitico.gs
API https://apps.superlogica.net/imobiliaria/api
A Taxa Adm Realizada vem da API (/repasses). PDF de movimentações serve apenas para validação/conferência — nunca como fonte de escrita na planilha.

2. Setup

  1. Abra a planilha no Google Sheets.
  2. Extensões → Apps Script e cole o .gs de produção.
  3. Defina CONFIG.SPREADSHEET_ID (ID da URL entre /d/ e /edit).
  4. Salve o projeto e recarregue a planilha.
  5. Menu Configurar Tokens → app_token e access_token.
  6. Testar API → Importar por período.

Tokens ficam em Script Properties. Nunca versionar no Git.

4. Fluxo da Taxa Adm

Como o script monta a aba Taxa Adm Realizada.

flowchart TD
  A[GET /contratos ativos] --> B[IDs das cobranças do período]
  B --> C[Pesquisa gêmeos inativos]
  C --> D[GET /repasses por idContrato]
  D --> E[Filtro local de datas m/d/Y]
  E --> F[Rateio por beneficiário]
  F --> G[Aba Taxa Adm Realizada]
  G --> H[Resumo Analítico]

Contratos ativos e inativos

  • Ativos: retornados por GET /contratos.
  • Inativos: a listagem padrão omite fl_ativo_con=0. Entram via IDs das cobranças do período e via GET /contratos?pesquisa={número do identificador}.
  • Coluna contrato_ativo = Ativo ou Inativo.

5. Regras importantes

TemaRegra
Fonte Sempre /repasses. PDF só valida.
Período Data em dt_credito_recb ou dt_repasse_rep ou dt_pagamento (parse m/d/Y).
Paginação API limita ~50/página. Continuar enquanto a página vier cheia.
Valor vl_txadm_rep → senão soma vl_txadm_rei → senão fixo/percentual sobre aluguel.
Número do contrato Dígitos iniciais de st_identificador_imo (não necessariamente o id interno).
Conferência jun/2026 ~351 só ativos · ~367 com inativos · PDF ouro 363 (externo).

6. CONFIG relevantes

ChavePapel
TAXA_ADM_SOMENTE_CONTRATOS_ATIVOS false = inclui IDs das cobranças (inativos com boleto)
TAXA_ADM_PESQUISAR_CONTRATOS_INATIVOS true = pesquisa gêmeos por número do identificador
REPASSES_ITENS_POR_PAGINA 50 (limite prático da API)
TAXA_ADM_INCLUIR_COMPOSICAO / …_DESPESAS Desligados por padrão (evitam duplicar a taxa do PDF)

8. Operação diária

  1. Use Importar por período com o mês desejado.
  2. Confira Resumo Analítico (seção repasses ativo × inativo).
  3. Analise a aba Taxa Adm Realizada (filtre por contrato_ativo se precisar).
  4. Em dúvida de total vs PDF: a API pode diferir algumas linhas/valores; a fonte oficial do script é a API.
