2. Objetivo

Automatizar o fluxo financeiro entre os dois sistemas, sem substituir as automações de planilha atuais.

Superlógica Imobiliárias Origem — contratos, despesas e parcelas de aluguel/compra.
Controlle Destino — lançamentos de entrada (contas a receber / receitas).
Prioridade da v1: envio Superlógica → Controlle. Retorno de pagamento (Controlle → Superlógica) permanece opcional.

Fluxo principal — Cobrança

  1. Ler no Superlógica as despesas/parcelas de contrato (aluguel e compra).
  2. Criar no Controlle um lançamento de entrada.
  3. Incluir o número do contrato na descrição (Contrato {n}).
  4. Guardar o vínculo (id despesa ↔ id lançamento) para não duplicar.

Retorno opcional — Pagamento

  1. Listar entradas pagas no Controlle com número de contrato.
  2. Localizar a despesa/parcela no Superlógica.
  3. Liquidar no Superlógica e marcar o pagamento como processado.

6. Regras de negócio

  1. Só sincroniza registros com número de contrato válido.
  2. Não recria no Controlle se a despesa Superlógica já foi sincronizada.
  3. No retorno opcional: não reliquida se o pagamento Controlle já foi processado.
  4. Locação e compra usam categorias diferentes no Controlle.
  5. Em erro parcial: registrar falha, seguir o lote, resumir no final.
